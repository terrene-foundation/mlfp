Lesson 2.7 CUPED and Causal Inference

A/B tests from Lesson 2.4 are the gold standard for causal inference, but they are often noisy — the variance in your metric swamps the treatment effect. This lesson introduces the single most impactful variance-reduction technique in industry (CUPED), shows how to detect when your experiment is broken (SRM), and extends causal reasoning to settings where randomisation is impossible (Difference-in-Differences). By the end you will be able to quantify how much variance CUPED removes (a fraction $\rho^2$ — 49% when the pre-period correlation is 0.7, but only about 4% on this course's experiment data) and measure policy effects from observational data.

CUPED: Control Using Pre-Experiment Data

CUPED is variance reduction using a covariate that is measured before the experiment starts. The idea is simple: if you know a user's spending last month, you can adjust their spending this month by how much it deviates from their historical average. The adjusted metric has lower variance, which means you can detect smaller effects or declare significance faster.

The derivation

Let $Y$ be the post-experiment metric and $X$ be the pre-experiment covariate. Define the adjusted metric:

$$Y_{\text{adj}} = Y - \theta \cdot (X - \mathbb{E}[X])$$

We want to choose $\theta$ to minimise the variance of $Y_{\text{adj}}$:

$$\text{Var}(Y_{\text{adj}}) = \text{Var}(Y) - 2\theta \cdot \text{Cov}(Y, X) + \theta^2 \cdot \text{Var}(X)$$
quadratic in $\theta$ minimum at $\theta^* = \text{Cov}(Y, X) / \text{Var}(X)$

Substituting $\theta^*$ back:

$$\boxed{\;\text{Var}(Y_{\text{adj}}) = \text{Var}(Y)(1 - \rho^2)\;}$$
$\rho$ = correlation between $Y$ and $X$ $\rho = 0.7 \Rightarrow$ 51% of the variance remains: a 49% reduction

The key insight: the higher the correlation $\rho$ between the pre and post metrics, the more variance CUPED removes — the reduction is exactly $\rho^2$. When a user's spending last month predicts this month well ($\rho$ of 0.6–0.8), that is a 36–64% reduction, worth the same as 1.6–2.8 times as many users. When the pre-period metric is a weak predictor, the gain is small, as the worked example below shows.

$\rho$Variance reduction $\rho^2$Effective sample multiplier $1/(1-\rho^2)$
0.39%1.10x
0.525%1.33x
0.749%1.96x
0.981%5.26x

(Read the table carefully: at $\rho = 0.7$ the remaining variance is $1 - 0.49 = 51\%$, so the reduction is 49%.)

Implementation

The course experiment (experiment_data.parquet) records each user's revenue during the test and pre_metric_value, measured before randomisation. Use only the control and treatment_a arms — the pair whose allocation passes the SRM check (Lesson 2.4). Estimate one $\theta$ on both arms pooled, so the same adjustment is applied to every user. 

import numpy as np
import polars as pl
from scipy import stats
from shared import MLFPDataLoader

df = (
    MLFPDataLoader().load("mlfp02", "experiment_data.parquet")
    .filter(pl.col("experiment_group").is_in(["control", "treatment_a"]))
)
y = df["revenue"].to_numpy()
x = df["pre_metric_value"].to_numpy()          # measured BEFORE randomisation

theta = np.cov(y, x)[0, 1] / np.var(x, ddof=1)  # pooled over both arms
y_adj = y - theta * (x - x.mean())
rho = np.corrcoef(y, x)[0, 1]

print(f"theta = {theta:.3f}, rho = {rho:.3f}, 1 - rho^2 = {1 - rho**2:.3f}")
print(f"Variance reduction: {1 - np.var(y_adj) / np.var(y):.1%}")
theta = 0.681, rho = 0.210, 1 - rho^2 = 0.956
Variance reduction: 4.4%

The measured reduction equals $\rho^2 = 0.044$, exactly as the derivation predicts — and it is small, because last period's metric explains little of this period's revenue in this data.

🔵 Theory

CUPED is mathematically identical to the residuals of a linear regression of $Y$ on $X$. The optimal $\theta$ is the regression slope $\hat\beta = \text{Cov}(Y, X) / \text{Var}(X)$, and the adjusted metric $Y - \hat\beta(X - \bar X)$ is the regression residual shifted back to the original mean. CUPED is regression adjustment applied to A/B test analysis.

🟣 Advanced

CUPED requires that the pre-experiment covariate is independent of the treatment assignment. Since $X$ is measured before the experiment, this is guaranteed by the randomisation. If you use a post-experiment covariate, you risk adjusting away the treatment effect itself.

SRM: Sample Ratio Mismatch

Before analysing any A/B test, check the split against the split you designed. If you designed 50/50 but observe 52/48 on a large sample, something is wrong — bot filtering, redirect bugs, or population filters could be biasing one arm. If the design was unequal (the course experiment is 40/35/15/10), test against those shares; testing an unequal design against 50/50 "detects" SRM every time.

Detection

import numpy as np
from scipy import stats

observed = np.array([4800, 5200])     # control, treatment
design = np.array([0.5, 0.5])         # the DESIGNED split, not always 50/50
chi2, p_srm = stats.chisquare(observed, observed.sum() * design)

print(f"Chi-squared: {chi2:.2f}, p = {p_srm:.5f}")
if p_srm < 0.01:
    print("SRM detected — investigate before analysing results")
Chi-squared: 16.00, p = 0.00006
SRM detected — investigate before analysing results

A 48/52 split looks harmless, but with 10,000 users it is a clear SRM: a fair 50/50 randomiser would produce an imbalance this large about 6 times in 100,000 experiments.

⚠ Warning

If SRM is detected, do not trust the A/B test results. Common causes: bots filtered unevenly, a redirect failing for one variant, or a population filter applied after randomisation. Fix the root cause and re-run the experiment.

Difference-in-Differences

When randomisation is impossible — you cannot randomly assign Singapore's cooling measures policy to some districts and not others — you need observational causal inference. Difference-in-Differences (DiD) compares the change in a treated group to the change in an untreated group:

$$\text{ATT} = (\bar{Y}_{\text{treat,post}} - \bar{Y}_{\text{treat,pre}}) - (\bar{Y}_{\text{control,post}} - \bar{Y}_{\text{control,pre}})$$
ATT = Average Treatment Effect on the Treated first difference removes level effects; second difference removes time effects

The parallel trends assumption

DiD requires that, absent treatment, the treated and control groups would have followed parallel trends. You cannot test this directly (it is about the counterfactual), but you can check it in the pre-period:

Exercise 7.4 uses a simulated quarterly panel of HDB-style transactions around a hypothetical cooling measure that applies only to Central-region flats (treated) and not to Non-Central flats (control); the true effect built into the simulation is −20,000. Its helper parallel_trends_test fits, on the pre-period only,

$$\text{price} = b_0 + b_1\,\text{period} + b_2\,\text{central} + b_3\,(\text{central} \times \text{period}) + \varepsilon$$

and tests $H_0: b_3 = 0$ — the two groups' pre-period slopes are equal. 

from shared.mlfp02.ex_7 import parallel_trends_test, simulate_hdb_cooling_panel

panel = simulate_hdb_cooling_panel()                        # parallel by construction
pt = parallel_trends_test(panel)
print(f"slope difference = {pt['slope_diff']:,.0f}  p = {pt['p_value']:.3f}")

diverging = simulate_hdb_cooling_panel(central_extra_growth=5_000)
pt_bad = parallel_trends_test(diverging)
print(f"slope difference = {pt_bad['slope_diff']:,.0f}  p = {pt_bad['p_value']:.4f}")
slope difference = 1,045  p = 0.559
slope difference = 6,045  p = 0.0007

The first panel passes; the second, where Central prices were already rising 5,000 a quarter faster before the measure, fails — and on that panel DiD returns about +6,800 instead of the true −20,000. Passing the pre-period check is necessary, not sufficient: it cannot prove the trends would have stayed parallel after the policy.

⚠ Warning

If the pre-period trends are not parallel, DiD is invalid. The treatment effect estimate will be biased by the divergent trends. Placebo tests — running DiD on a fake treatment date in the pre-period — help diagnose this.

Worked Example: CUPED, then DiD

📝 Goal

(1) Compare the treatment effect on revenue with and without CUPED on the course experiment (control vs treatment_a). (2) Estimate the effect of the hypothetical Central-only cooling measure on Exercise 7.4's simulated panel, with a confidence interval and a placebo test.

Step 1 — Raw and CUPED effects.

Continue from the Implementation code above (y, y_adj already computed).

treat = (df["experiment_group"] == "treatment_a").to_numpy()

for name, v in [("raw", y), ("CUPED", y_adj)]:
    diff = v[treat].mean() - v[~treat].mean()
    se = np.sqrt(v[treat].var(ddof=1) / treat.sum()
                 + v[~treat].var(ddof=1) / (~treat).sum())
    t, p = stats.ttest_ind(v[treat], v[~treat], equal_var=False)
    print(f"{name:>5s}: effect {diff:.2f}  SE {se:.3f}  t = {t:.1f}  p = {p:.2g}")
  raw: effect 3.16  SE 0.164  t = 19.3  p = 6.5e-83
CUPED: effect 3.18  SE 0.160  t = 19.8  p = 1.7e-87

The effect estimate barely moves (CUPED does not change what you estimate, only how precisely), and the standard error shrinks by about 2% — the square root of the 4.4% variance reduction. Here CUPED is honest but not worth much; with a pre-period metric correlated at $\rho = 0.7$ the same code would cut the SE by 30% and the required sample by 49%.

Step 2 — DiD estimate with a confidence interval. 
from shared.mlfp02.ex_7 import did_cells, diff_in_diff

res = diff_in_diff(did_cells(panel))     # panel from the parallel-trends check
print(f"ATT = {res['did_estimate']:,.0f}  "
      f"95% CI [{res['ci_lo']:,.0f}, {res['ci_hi']:,.0f}]  z = {res['z']:.2f}")
ATT = -23,208  95% CI [-31,702, -14,713]  z = -5.36

The estimate is −23,208 against a true effect of −20,000: the gap is sampling noise, and the interval covers the truth.

Step 3 — Placebo test.

Pretend the measure started at period 3, inside the pre-period, and rerun DiD on pre-period data only. A real effect cannot exist there, so a credible design should find none. 

placebo = (
    panel.filter(pl.col("post") == 0)
    .with_columns(post=(pl.col("period") >= 3).cast(pl.Int64))
)
pl_res = diff_in_diff(did_cells(placebo))
print(f"Placebo ATT = {pl_res['did_estimate']:,.0f}  "
      f"95% CI [{pl_res['ci_lo']:,.0f}, {pl_res['ci_hi']:,.0f}]")
Placebo ATT = 2,149  95% CI [-9,827, 14,125]

The placebo interval comfortably includes zero, which supports (but cannot prove) the parallel-trends assumption behind the real estimate.

Common Mistakes

⚠ Mistake 1: Using a post-experiment covariate in CUPED

The covariate must be measured before randomisation. A post-experiment covariate may be affected by the treatment, and adjusting for it removes part of the effect you are trying to measure.

⚠ Mistake 2: Ignoring SRM

Always check the split against the designed allocation before analysing results. A 52/48 split on a large 50/50 experiment is a red flag — the p-value on your treatment effect is meaningless if the groups are systematically different.

⚠ Mistake 3: Applying DiD without checking parallel trends

DiD with divergent pre-trends gives a biased estimate. Always plot the pre-period trends and run a placebo test.
