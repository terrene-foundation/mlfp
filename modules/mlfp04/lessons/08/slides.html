MF is a special case of NN

Network architecture

Each connection = weight. Each node = linear transform + activation. Hidden activations = embeddings.

One forward pass: numbers in, numbers out

Forward pass

\[ \mathbf{z}^{(l)} = W^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)} \quad,\quad \mathbf{a}^{(l)} = f(\mathbf{z}^{(l)}) \] 

z1 = X @ W1 + b1;    a1 = relu(z1)
z2 = a1 @ W2 + b2;   a2 = relu(z2)
z3 = a2 @ W3 + b3;   y_hat = z3

Loss function

Regression: Mean Squared Error

\[ \mathcal{L} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 \]

Classification: Cross-Entropy

\[ \mathcal{L} = -\frac{1}{n} \sum_{i=1}^{n} \sum_{c=1}^{C} y_{ic} \log \hat{y}_{ic} \]

Loss functions taxonomy

LossTaskFormula
MSE / MAERegression (MAE: robust)$\frac{1}{n}\sum(y-\hat y)^2$ / $\frac{1}{n}\sum|y-\hat y|$
Binary CEBinary classification$-[y\log\hat y + (1-y)\log(1-\hat y)]$
Cross-entropyMulti-class (after softmax)$-\sum_k y_k \log \hat y_k$
FocalImbalanced classes$-(1-\hat y)^\gamma\, y \log \hat y$
ContrastiveSimilarity learningpull similar pairs together, push dissimilar apart
TripletMetric learning$\max(0,\ d(a,p) - d(a,n) + m)$
KL divergenceDistribution matching$\sum P(x) \log \frac{P(x)}{Q(x)}$
ReconstructionAutoencoders (M5.1)$\lVert x - \hat x\rVert^2$
Reference slide; the loss defines what the network optimises. Triplet loss takes an anchor a, positive p and negative n and asks d(a,p) to be at least a margin m smaller than d(a,n) — the basis of face matching and embedding search. Focal loss down-weights easy examples so rare classes are not drowned out.

Backpropagation — chain rule

\[ \frac{\partial \mathcal{L}}{\partial W^{(1)}} = \frac{\partial \mathcal{L}}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial \mathbf{a}^{(2)}} \cdot \frac{\partial \mathbf{a}^{(2)}}{\partial \mathbf{z}^{(2)}} \cdot \frac{\partial \mathbf{z}^{(2)}}{\partial \mathbf{a}^{(1)}} \cdot \frac{\partial \mathbf{a}^{(1)}}{\partial \mathbf{z}^{(1)}} \cdot \frac{\partial \mathbf{z}^{(1)}}{\partial W^{(1)}} \]
🟢 Foundations: just the product rule from calculus, applied layer by layer from output to input.

Chain rule: multiply gradients backward through the graph

Gradient descent

\[ W \leftarrow W - \eta \, \frac{\partial \mathcal{L}}{\partial W} \]

Activation functions — shape gallery

More activations — and the output layer

FunctionFormulaUseNotes
PReLU$\max(az, z)$, $a$ learnedHidden layersLeaky ReLU with a learned slope
ELU$z$ if $z>0$, else $\alpha(e^z - 1)$Hidden layersSmooth; negative outputs push the mean toward 0
Swish / SiLU$z \cdot \sigma(z)$Hidden layers, modern CNNs / LLMsSmooth, non-monotonic near 0
Softmax$\dfrac{e^{z_i}}{\sum_j e^{z_j}}$Multi-class outputOutputs positive, sum to 1

Output layer by task: regression → identity; binary → sigmoid; multi-class → softmax (paired with cross-entropy). The ReLU variants all keep a non-zero gradient for $z < 0$ — the dead-unit fix Exercise 8.2 measures.

Spec 4.8 lists PReLU, ELU, Swish and softmax. PyTorch calls Swish SiLU. Exercise 8.2 compares ReLU, GELU, Tanh and SiLU on the same task and counts dead units under different initialisations.

Dropout — regularisation by deletion

Randomly zero out neurons during training (p = 0.1–0.5). Forces redundant representations. Off at inference.

Batch normalisation

\[ \hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} \;,\quad y_i = \gamma\,\hat{x}_i + \beta \]
  • Normalise each layer's inputs to zero mean, unit variance.
  • $\gamma$, $\beta$ are learnable — network can undo the normalisation if needed.
  • Stabilises training, enables higher learning rates, slight regularisation effect.

Learning rate schedules + early stopping

Hidden layers = automated feature engineering

🟣 Advanced: hidden activations are learned representations. First layer: simple features. Deeper layers: complex compositions. Output layer: supervised prediction on learned features. This is representation learning.
  • Hidden layers perform unsupervised feature discovery.
  • Output layer performs supervised prediction.
  • Node values = embeddings (same as 4.7, but non-linear).
  • Universal approximation: ONE hidden layer with a non-polynomial activation and enough units can approximate any continuous function on a bounded domain to any accuracy. Depth buys efficiency (far fewer units), not possibility.

From scratch: one hidden layer on HDB prices


import numpy as np
from shared import MLFPDataLoader

hdb = MLFPDataLoader().load("mlfp01", "hdb_resale.parquet").sample(5000, seed=42)
X = hdb.select("floor_area_sqm", "lease_commence_date").to_numpy().astype(float)
y = hdb["resale_price"].to_numpy()[:, None] / 1e5          # price in S$100k
X = (X - X.mean(0)) / X.std(0)                              # standardise

rng = np.random.default_rng(42)
W1 = rng.normal(0, np.sqrt(2 / 2), (2, 16)); b1 = np.zeros(16)   # He init
W2 = rng.normal(0, np.sqrt(2 / 16), (16, 1)); b2 = np.zeros(1)
lr, n = 0.05, len(X)
for epoch in range(500):
    z1 = X @ W1 + b1; a1 = np.maximum(0, z1)                # forward
    y_hat = a1 @ W2 + b2
    d_out = 2 * (y_hat - y) / n                             # dL/dy_hat (MSE)
    dW2 = a1.T @ d_out;  db2 = d_out.sum(0)                 # backward
    d_z1 = (d_out @ W2.T) * (z1 > 0)                        # ReLU gate
    dW1 = X.T @ d_z1;    db1 = d_z1.sum(0)
    W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2

Run it: MSE falls from 107 to 26.4 (S$100k)². Two features explain only ~18% of price variance — location is missing, not the maths.

Common mistakes

  1. Zero init — symmetry never broken. Use He init for ReLU.
  2. Dropout at inference — predictions become noisy. Turn it off.
  3. LR too high — loss oscillates. Start 10⁻³, use schedule.
  4. No early stopping — overfits for 1000 epochs when 200 was enough.
  5. Exploding gradients — loss jumps to NaN. Clip the gradient norm: torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0).
