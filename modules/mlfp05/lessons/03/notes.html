Speaker Notes — Lesson 5.3 RNNs and Sequence Models

Total time: ~60 minutes  ·  19 slides  ·  ~3 min per slide average

Temporal feature learning. The intellectual arc: why vanilla RNNs forget (the product-of-Jacobians argument), how the LSTM's cell state highway fixes it (and is the ancestor of ResNet's skip), and the six equations every student should be able to reconstruct. The worked scenario is honest forecasting: real STI daily bars with a persistence baseline stated up front — daily prices are close to a random walk, so "tomorrow = today" is the number to beat.

Slide 1~1 minTitle

RNNs and Sequence Models

Open with the arc: "5.2 learned spatial features. Today: temporal ones — vanilla RNN, LSTM, GRU, and a first taste of temporal attention, which 5.4 generalises into the Transformer."

→ "Why sequences break the architectures we have."
Slide 2~3 minWhy sequences

Sequences need their own architecture

Walk the two properties. Variable length: 5 words or 500 — no fixed input size, so the fixed-shape layers from 5.2 and M4 don't apply. Temporal dependency: "bank" near "river" means something different from "bank" near "deposit" — context within the sequence changes the meaning.

Then the recurrent idea: "Carry a hidden state forward, update it step by step, reuse the same weights at every step. Memory as a loop."

→ "The update rule."
Slide 3~3 minVanilla RNN

The vanilla RNN update

Walk the equation: $h_t = \phi(W_{xh}x_t + W_{hh}h_{t-1} + b)$. "The new hidden state is a squashed sum of 'what's coming in now' and 'what I remember'. The same weight matrices at every time step — weight sharing exactly like a conv kernel, but across time instead of space."

→ "Unrolled, it looks like this."
Slide 4~2 minUnrolled RNN

Same weights at every time step

Walk the unrolled diagram: the same cell stamped at $t-1$, $t$, $t+1$, the hidden state passing along the chain. "It's one network reused $T$ times — which is why training it means backpropagating through time, down the whole chain. Keep that picture; the failure mode lives there."

→ "The failure, visualised."
Slide 5~3 minGradient decay picture

Why RNNs forget: gradients vanish; LSTMs maintain the signal

Walk the comparison chart: the vanilla RNN's gradient magnitude collapsing toward zero as you step back through time — by $t = 1$ it's essentially zero. The LSTM's cell-state highway keeps the magnitude alive across all steps.

"A gradient of zero means no learning. The vanilla network cannot learn long-range dependencies — not 'struggles to', cannot. The next slide shows why, algebraically."

→ "The algebra of forgetting."
Slide 6~3 minVanishing gradients

The cruel flaw: vanishing gradients

State the mechanism: backprop through a long sequence is a product of $T$ Jacobians. "Each Jacobian with norm below 1 → the product shrinks exponentially: vanishing. Each above 1 → it blows up: exploding. You're squeezed between two failure modes."

"Vanilla RNNs struggle to learn dependencies more than a few dozen steps back. The 1997 fix: LSTM."

→ "The fix: a highway for the state."
Slide 7~4 minCell state

LSTM: cell state highway

Introduce the second state: "Alongside the hidden state, the LSTM carries a cell state — updated by a gated sum: scale the old content by a forget gate, add new content. Three gates control it."

Then the key sentence: "The path is additive — while the forget gate stays near 1, the gradient flows through almost unchanged. That is the magic." Read the blue box: "The cell state is the ancestor of ResNet's skip connections (2015). Hochreiter and Schmidhuber had the gradient-highway idea eighteen years earlier."

→ "The highway, drawn."
Slide 8~3 minHighway picture

The cell state highway: why LSTMs remember

Walk the cell diagram: the cell state running along the top like a conveyor belt, with the forget gate's multiplier and the input gate's addition as the only two operations on it. "No weight matrix, no squashing on that path — just scale and add. The gradient hitchhikes the belt."

→ "The six equations."
Slide 9~5 minSix equations

LSTM: three gates + candidate, six equations

Read the six equations in order, naming each: forget $f_t$ (sigmoid — keep how much of the past?), input $i_t$ (sigmoid — accept how much new content?), candidate $\tilde{C}_t$ (tanh — what is the new content?), cell update $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ (forget some past, accept some new — additive), output $o_t$ (sigmoid — how much of the cell to reveal?), hidden $h_t = o_t \odot \tanh(C_t)$.

"Six equations, three gates, one candidate. Have the class close their laptops and reconstruct the cell-update line from memory — it's the one that matters."

→ "Walk them once more, in words."
Slide 10~3 minEquations in words

Walk the equations

Walk the six bullets as questions and answers. Forget ∈ [0,1]: "keep how much of past cell state?" Input ∈ [0,1]: "accept how much new content?" Candidate ∈ [−1,1]: "what is the new content?" Cell update: forget some past + accept some new — additive. Output: "how much of the cell to reveal?" Hidden: output-gated tanh of the cell.

"The gates are learned — the network decides what to remember and when to forget, per time step, per feature. That's what makes it more than a fixed filter."

→ "Why the gradient survives."
Slide 11~3 minGradient highway

Why it works: gradient highway

Contrast the two derivatives. Vanilla RNN: $\partial h_t / \partial h_{t-1}$ involves $W_{hh}$ and a tanh derivative — both shrink it, exponentially. LSTM: $\partial C_t / \partial C_{t-1} \approx f_t$ — when the forget gate is near 1, the gradient passes through nearly unchanged.

Read the green box: "Same insight as ResNet: give the gradient an additive path back. 5.2's skip connection and today's cell state are one idea."

→ "The simpler cousin."
Slide 12~3 minGRU

GRU — a simpler cousin (2014)

Walk the four equations. Update gate $z_t$: interpolate between the old hidden state and the candidate. Reset gate $r_t$: how much of the past to expose to the candidate. One merged gate structure, no separate cell state.

"Fewer parameters, usually competitive with LSTM. Reach for GRU when the data is modest; LSTM when you need the explicit cell memory. Both are nn.LSTM / nn.GRU away."

→ "In PyTorch."
Slide 13~4 minLSTM regressor

LSTM regressor in PyTorch

Walk the code: nn.LSTM(input_size, hidden_size=32, num_layers=2, batch_first=True, dropout=0.1) feeding a linear head on the final time step. Two details to name: batch_first=True gives the modern (B, L, F) layout, and out[:, -1, :] takes the last step's hidden state as the sequence summary.

Platform note for M-series Macs: on torch 2.12 with Apple MPS, a 2-layer nn.LSTM with inter-layer dropout=0.1 trains badly (val loss stuck ~10× above CPU). If students on MPS see a flat val curve: run on CPU, or set dropout to 0. Noted upstream; exercise configs account for it.
→ "Training — and the clip that's not optional."
Slide 14~3 minGradient clipping

Training — clip those gradients

Walk the loop: the same Adam + zero_grad/backward/step structure as always, with the starred line — clip_grad_norm_(model.parameters(), max_norm=1.0) between backward and step.

"Remember the exploding half of the vanishing/ex exploding dilemma: without clipping, an occasional exploding batch turns the loss into NaN and the run is over. The clip rescales the whole gradient vector when its L2 norm exceeds 1.0 — direction preserved, magnitude capped. Standard practice, not a tweak."

→ "Better than 'last step only': attention."
Slide 15~4 minTemporal attention

Temporal attention

Frame the limitation: "The regressor squeezed the whole sequence into the last time step. Why should step 20 of 20 carry everything?" Walk the code: a small scorer maps every step's hidden state to a score, softmax turns scores into weights, and the context is the weighted sum over time.

"Learned, content-dependent pooling over time. Read the closing line: 'Preview of 5.4 — this is exactly what the Transformer generalises.' The attention you're about to meet is this idea with the recurrence removed."

→ "The Singapore scenario."
Slide 16~4 minSTI scenario

Singapore scenario: forecasting the STI

Walk the setup: Exercise 5.3 uses real daily bars for the Straits Times Index (2010–2024, cached). Input: 20 past trading days × 4 features — Close, High, Low, Volume — z-scored on the training period. Target: the next 5 closing prices.

Two honesty points. "RSI / MACD / Bollinger features are a natural extension — deliberately not in the exercise feature set; you'll feel how far raw prices go. And the baseline rule: daily prices are close to a random walk, so always compare against 'tomorrow = today' persistence before claiming skill. A model that can't beat persistence is an expensive random number generator."

→ "How to score sequence models."
Slide 17~3 minMetrics

Metrics for sequence models

Walk the table. MSE / MAE for regression — prices, demand; MAE robust as always. Perplexity — the exponential of mean negative log-probability — for language models; lower is better, and M6 will live on it. BLEU for machine translation. Sequence accuracy for classification.

→ "Four traps."
Slide 18~3 minTraps

Four traps

Walk the four. One: forgetting gradient clipping — always clip the L2 norm to 1.0. Two: wrong batch_first — the default layout is (L, B, F); modern code is (B, L, F), and a silent transpose here poisons everything downstream. Three: stateful state leakage — don't reuse hidden state across unrelated sequences; the memory of one customer must not leak into another. Four: BPTT memory blow-up — truncate when seq_len × hidden × batch gets large.

→ "Reflection."
Slide 19~2 minReflection

Reflection

Walk the checklist: explain vanishing gradients and the LSTM fix, write the six equations from memory, build LSTM/GRU regressors, apply gradient clipping as standard practice, and add temporal attention as a weighted sum over steps. Tease 5.4: "No recurrence, pure attention — the Transformer."

→ End of Lesson 5.3. Ten-minute break.
