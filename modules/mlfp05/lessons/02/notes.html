Speaker Notes — Lesson 5.2 CNNs and Computer Vision

Total time: ~60 minutes  ·  18 slides  ·  ~3.5 min per slide average

Spatial feature learning. The first half is mechanics — convolution and pooling with real numbers, the one output-size formula. The second half is the ResNet idea and its two refinements (basic block, SE), closing with the OnnxBridge export students will run in Exercise 5.2. Two precision points: translation equivariance (not invariance), and export-does-not-validate — parity is a separate step with its own assert.

Slide 1~1 minTitle

CNNs and Computer Vision

Open with the arc: "5.1 was autoencoders and the PyTorch training loop. Today: the architecture that owns images — LeNet to ResNet to SE to ViT in one hour."

→ "Why not just flatten the image?"
Slide 2~4 minWhy convolutions

Why convolutions?

Walk the arithmetic of the alternative: "A 224×224 colour image has 150,528 pixels. A fully connected layer to 1,000 units needs 150 million parameters — and learns nothing about spatial structure."

Then the two properties convolutions exploit. Local structure: adjacent pixels are correlated, so a small filter suffices. And say this precisely — students mix it up: "Translation equivariance — shift the cat and its feature map shifts with it. The detector responds the same way at every position; pooling then adds a little local invariance on top. A convolution uses the same small filter at every position — weight sharing is the whole trick."

→ "The operation itself, with numbers."
Slide 3~4 minConvolution

Convolution: slide, multiply, sum

Walk the worked figure. The 5×5 input, the 3×3 kernel, and the top-left window highlighted. Element-wise products: 1, 0, −2, 8, 0, 3, 0, 0, −1. Sum: 9 — one output value. Slide the window, repeat, fill the 3×3 output grid.

Read the formula line: output size $(W - F + 2P)/S + 1 = (5 - 3 + 0)/1 + 1 = 3$. "Slide the kernel across every position. At each: multiply, sum, write one output value. That is every CNN ever built."

→ "Pooling."
Slide 4~3 minPooling

Pooling: keep the strongest signal, halve the size

Walk the 4×4 → 2×2 figure: each coloured 2×2 window keeps only its maximum — 5, 8, 7, 9. "No learnable parameters — a fixed aggregation. The spatial size halves; the strongest activations survive; and a little local translation invariance comes free — wiggle the input by a pixel and the max usually doesn't move."

→ "The one formula you must memorise."
Slide 5~3 minConv arithmetic

Conv arithmetic — the one formula

Walk the boxed formula: $W_{\text{out}} = \lfloor(W - F + 2P)/S \rfloor + 1$. Then the two patterns that cover ninety percent of practice. "Same": stride 1 with $P = (F-1)/2$ — 28×28 stays 28×28. "Halving": stride 2 with $F = 3$, $P = 1$ — 28×28 becomes 14×14.

"When a shape error bites you — and it will — this formula is where you start debugging."

→ "Twenty years in one table."
Slide 6~3 minHistory

A short history

Walk the table briskly, one idea per row. 1998 LeNet: first working CNN. 2012 AlexNet: ReLU, dropout, GPUs, ImageNet — the deep-learning big bang. 2014 VGG: only 3×3 filters — depth is what matters. 2014 Inception: parallel filter sizes in one block. 2015 ResNet: skip connections — bold, because it's the idea the rest of the lesson builds on. 2017 SENet: channel attention. 2020 ViT: transformer on image patches.

→ "The ResNet idea."
Slide 7~4 minResNet idea

The ResNet idea

Set up the mystery: "Before ResNet, adding layers past ~20 hurt accuracy — and not from overfitting, because training error rose too, and not from vanishing gradients, because BatchNorm was already there. Deep plain nets are simply hard to optimise."

Then the fix: $H(x) = F(x) + x$. "Learn the residual and add the input back. The skip gives gradients a clear path backward. And the deeper point: if $F$ learns zero, the block is the identity — so an extra block is easy to make harmless. Depth stops being a risk and becomes an option."

→ "The block itself."
Slide 8~3 minBasic block

ResNet basic block

Walk the diagram: $x$ enters, two Conv+BN(+ReLU) stages compute $F(x)$, the dashed amber identity shortcut carries $x$ around them, and the circled plus adds them before the final ReLU. "Notice the second convolution has no ReLU after it — the activation comes after the addition. The order matters: add first, then activate."

→ "In PyTorch."
Slide 9~3 minBasicBlock code

BasicBlock in PyTorch

Walk the code: two 3×3 convolutions with padding 1 (the "same" pattern from the formula slide), batch norms, and the forward pass — save the input as identity, compute the two conv stages, then the magic line: out = out + identity.

"Fifteen lines for the most cited idea in modern vision. The bias is off in the convs because BatchNorm's $\beta$ already provides one — a small detail worth noticing when you read real ResNet code."

→ "One more drop-in: channel attention."
Slide 10~4 minSE

Squeeze-and-Excitation

Walk the three steps. Squeeze: global-average-pool each channel to one number — the channel's overall strength. Excite: a tiny MLP with a sigmoid — a learned weight in (0, 1) per channel. Scale: multiply each channel by its weight. "The network learns which channels matter, per input — channel attention."

Read the payoff: "SE-ResNet-50 at reduction 16: about 10% more parameters for about 1.5 points lower top-1 error on ImageNet. Cheap accuracy — which is why SE blocks show up everywhere."

→ "The code."
Slide 11~3 minSE code

SE block code

Walk the code: two linear layers with a reduction bottleneck (floored at 4 units), then forward — x.mean(dim=[2,3]) squeezes, ReLU then sigmoid excites, and x * s.view(b, c, 1, 1) rescales each channel by broadcasting. "Three tensor operations. Read the .view(b, c, 1, 1) carefully — that reshape is what makes per-channel scaling work."

→ "Assemble the network."
Slide 12~3 minStacking

Stacking them

Walk TinyResNetSE: a conv stem, then BasicBlock + SE at 16 channels, a stride-2 downsampling conv (the "halving" pattern), BasicBlock + SE at 32 channels, and an adaptive-average head to the class logits. "Stem, blocks, downsample, head — every ResNet variant is this skeleton with different numbers."

→ "Train it — nothing new, on purpose."
Slide 13~3 minTraining loop

Training loop — familiar territory

Walk the loop: Adam at 1e-3, cross-entropy, the zero_grad / backward / step trinity. Read the closing line: "Identical structure to M4.8 and to Lesson 5.1. The only change: cross-entropy instead of MSE. The toolkit generalises — that's the point of M4.8's two hours."

→ "The modern garnish."
Slide 14~3 minModern recipes

Modern training recipes

Walk the table. Kaiming init: variance $2/n_{\text{in}}$ for ReLU — fast convergence (you met it in 4.8's from-scratch net). Mixed precision: FP16 forward with FP32 master weights — up to 2× speed and less memory, GPU-dependent. Mixup: blend pairs of inputs and labels — regularisation, about +1% accuracy. Label smoothing: soft targets — better calibration. Cosine LR schedule: anneal along a cosine — +0.5–1%.

→ "Ship it: ONNX export."
Slide 15~4 minOnnxBridge export

Exporting with OnnxBridge

Walk the code — this is the exact Exercise 5.2 file-03 pattern. The FlatImageAdapter wraps the ResNetSE so serving accepts flat pixel rows; .eval() first. Note the sample input: two rows — "a batch of 1 can freeze the batch size into the traced graph; trace with two."

Then the contract — read it word for word: "Export and parity are two explicit steps: export does not validate, and on failure it returns success=False rather than raising — so assert it. Then bridge.validate(serving, path, x.numpy(), tolerance=1e-3) gives PyTorch-vs-ONNX-Runtime parity and a max diff. Export first, prove parity second."

→ "The post-convolution era."
Slide 16~3 minViT

Vision Transformers in one slide

Walk the three steps: split the image into 16×16 patches and flatten each to a vector; add a learned position embedding per patch; feed the sequence to a standard Transformer encoder — Lesson 5.4's machine, eating images.

Read the verdict: "For very large datasets, ViT ≥ CNN. For small datasets, CNN still wins — the convolutional inductive bias is free data. Architecture choice is a data-size question, not a fashion question."

→ "Four traps."
Slide 17~3 minTraps

Four traps

Walk the four. One: forgetting model.eval() — batch norm uses batch statistics in train mode and running averages in eval; export or evaluate in train mode and your numbers are subtly wrong. Two: spatial mismatch in the skip — when downsampling changes the shape, the shortcut needs a 1×1 conv to match. Three: LR too high for deep nets — start at 1e-3 with Adam; halve on NaN. Four: .view(b, -1) vs flatten — use torch.flatten or nn.Flatten; view breaks on non-contiguous tensors.

→ "Reflection."
Slide 18~2 minReflection

Reflection

Walk the checklist: the output-size formula, building a ResNet basic block and explaining the skip, adding SE for channel attention, training with Adam + cross-entropy, exporting with OnnxBridge, and knowing when ViT beats CNN. Tease 5.3: "From spatial to temporal — RNNs and LSTMs, sequences with memory."

→ End of Lesson 5.2. Ten-minute break.
